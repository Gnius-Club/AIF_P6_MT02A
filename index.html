🎯 Objetivo de Aprendizaje

Los estudiantes podrán: Comprender el gait planning como un proceso de coordinación interna y de robótica biomimética, y posteriormente usar Micro:Bit + XGO para controlar el desplazamiento lineal y la rotación mediante parámetros de velocidad.

🤖 Prompt de Referencia para XOLO (Solo para Maestro)

⚠️ NOTA: XOLO ya conoce el tema de esta misión. Este prompt es SOLO de referencia en caso de emergencia técnica: 
Quiero aprender a programar rutas simples con el XGO usando comandos de avance y giro. Explícame primero qué significa “planificación de marcha” (gait planning) y por qué el robot necesita coordinar sus patas aunque yo solo use un comando como move_forward. Luego enséñame cómo usar: xgo.move_forward(speed), xgo.move_backward(speed), xgo.rotate_left(speed) y xgo.rotate_right(speed) para crear una ruta en forma de “L” o de “cuadrado”. Incluye protocolos de seguridad antes de ejecutar (ej: superficie estable, espacio libre, velocidad moderada). Después dame un mini reto: “Haz que el XGO avance 3 pasos, gire, avance 2 pasos y regrese al inicio”. Finalmente, evalúame con 3 preguntas rápidas para comprobar que entendí.

⚡ Puntos Esenciales de la Misión

🎓

Concepto Clave

Gait Planning (Planificación de marcha): Es como cuando nosotros caminamos; nuestro cerebro coordina cada músculo de las piernas para no caernos, igual que el robot coordina sus patas para moverse suavemente.

🔧

Habilidad Técnica

Usar el robot perro XGO para avanzar, retroceder y girar con precisión.

🧪

Experimentación

Probar con diferentes velocidades y tiempos de espera para entender limitaciones de equilibrio y precisión.

💬

Interacción con XOLO

XOLO ya conoce a cada estudiante y el tema de hoy. Solo abren el chat y comienzan a aprender. Tú guías el timing y motivación.

🚨 Resolución Rápida de Problemas

  • Si los alumnos no pueden ingresar a Gnius Space: Activa XOLO SOS en xolo.gnius.club para continuar la misión sin interrumpir la clase.

📊 Diapositiva 3: Brain Spark

1. 💬 Pide a XOLO que te ayude a crear:

"Ayúdame a imaginar un “circuito de entrenamiento” para el XGO como si fuera un perro robot explorador. Quiero que diseñe una ruta con giros, avances y retrocesos como si estuviera patrullando un territorio. Dame 3 ideas de rutas (fácil, media, difícil) y explícame qué cambia en cada una (velocidad, giros, distancia). Luego genera el código en Python para la ruta media, usando comandos básicos de movimiento. Finalmente incluye una idea creativa para que el robot “salude” al final de la patrulla con un movimiento simple."

2. 🔬 Experimenta y descubre con tu programa:

  • ¿El XGO completó la ruta sin perder el equilibrio?
  • ¿Qué pasa si aumentas la velocidad al máximo en un giro cerrado?
  • ¿Funciona igual la ruta en una superficie lisa que en una rugosa?
  • Si el robot coordina sus patas solo, ¿cómo se relaciona esto con el Gait Planning que explicó XOLO?
  • ¿En qué partes del movimiento notas que el robot imita a un animal real (biomimética)?

¡Es hora de crear, genios! Vamos a usar lo aprendido para diseñar un circuito de entrenamiento. Pidan a XOLO que los ayude a idear una ruta de patrullaje. El flujo es: idear con XOLO, obtener su VIBE y GCS, pasar eso a bloques en MakeCode y luego experimentar. Por ejemplo, podrían programar a su XGO para que patrulle un cuadrado y termine con un saludo especial. Recuerden probar primero en el simulador. Cuando estén listos, les entregaré el hardware. Si tienen errores o dudas, pregúntenle a XOLO, él los ayudará a depurar su código.
